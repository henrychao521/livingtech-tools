超音波避障：它量不到的東西比你想的多

「明明前面有障礙物，車子卻直接撞上去」——多半不是程式壞了，是感測器根本沒看到。

挑戰完成 0 / 3

📐 用聲音量距離

Trig 發射
40 kHz 超音波→ 碰到物體反射→ Echo 收到回音
量時間 t→ 距離 = t × 音速 ÷ 2

音速約 343 m/s（20°C）。除以 2 是因為聲音來回跑了兩趟。 常見寫法：距離(cm) = 脈波寬度(µs) / 58

🎯 三個挑戰

    🛡️ 程式上怎麼防

    • 把「量不到」當成一種狀態：讀到 0 或超出量程時，不要當成「距離 0 公分」直接煞車，也不要當成「前面沒東西」全速前進。
    • 連續讀數取中位數：連讀 3～5 次取中間值，可濾掉偶發的雜訊跳動。
    • 設定合理量程：只信任 3～200 cm 的讀值，超出就視為無效。
    • 加裝第二種感測器：超音波怕斜面與吸音材，紅外線怕深色與陽光——兩者互補。
    最危險的寫法

    if (距離 < 20) 停車; 看起來很合理，但當感測器讀到 0（量測失敗）時， 0 < 20 成立會讓車子莫名其妙停住； 反過來寫 if (距離 > 20) 前進; 則會在讀到 0 時直接撞上去。 務必先排除無效值再做判斷。
