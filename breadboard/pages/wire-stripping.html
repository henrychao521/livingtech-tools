① 5 種剝線方式對照

業界與實驗室常見有 5 種方式。正規做法是剝線鉗；沒有剝線鉗時才用兩鉗組合應急。本模組會教兩種，但要懂得「該選哪一種」是 108 課綱核心素養。

② 正規操作：剝線鉗 4 步驟

SparkFun、Adafruit、Engineer Fix 一致推薦的標準作法。關鍵是「對號入座」——把線對到符合線徑的剝線孔，是防呆機制。

1

① 量距

麵包板用約 6mm（壓接用 4–5mm）。露太短接觸不良、太長易短路。

2

② 對號入座

把線對到符合線徑的剝線孔。22 AWG 線 → 22 AWG 孔。對錯了會切到銅或夾不住。

3

③ 握緊 + 微轉

握緊把柄，輕微旋轉不到一圈，確保外皮整圈被劃破。

4

④ 順線軸直拉

沿著線的軸向往外拉，不是反向拉，避免外皮側向撕裂。

③ 應急操作：斜口鉗 + 尖嘴鉗 5 步驟 替代法

沒有剝線鉗時使用。關鍵不是「咬深」而是「壓力控制」——刃口剛好破皮即停。不能環繞 360°（V 形刃做不到），要轉位輕咬 3–4 次。

1

① 量距

同上，6mm 起算。

2

② 輕咬（壓力控制）

刃口對準外皮，剛好破皮即停。靠手感壓力，不是靠角度。

3

③ 轉位輕咬 3–4 次

每咬一下後把線轉 90°–120°，重複 3–4 次繞線一周。不是 360° 連續旋轉。

4

④ 順線軸直拉

尖嘴鉗夾外皮端，沿線軸直拉。不要反向施力。

5

⑤ 檢視銅芯

有刻痕、刮傷、斷股 → 整段剪掉重來。受傷的銅芯在彎折處會斷。

④ 工藝品質檢查 IPC-A-620 / NASA-STD-8739.4

國際電子線束標準看 3 項離散結果，不看「咬合深度百分比」。模擬器的判分也以這 3 項為準。

✓ 銅芯刻痕 IPC Class 2

合格：無刻痕，或刻痕深度 < 銅芯直徑 10%。
不合格：露出 base metal、刻痕 ≥ 10%、銅芯斷裂。

✓ 外皮端部齊整

合格：端面平整、無毛邊、無撕裂。
不合格：撕裂、毛邊外露、端面不齊整。

✓ 露出長度合宜

合格：依用途介於 4–9mm（壓接 4–5，麵包板 6–9）。
不合格：過短接觸不良、過長易短路。

✓ 多芯線斷股數

合格：依 IPC Class 規定（一般 ≤ 總股數的 15%）。
不合格：超過容許斷股、毛羽散開、未絞合。

⑤ 剝線挑戰：模擬手感

下面三關，依工具與線徑挑戰。判分依據 IPC-A-620 三項結果：銅芯刻痕、外皮端平整、露出長度。

⑥ 教師備課提醒

  • 工具選擇是核心素養：讓學生實際體驗剝線鉗與兩鉗組合的差異，理解「為什麼有專用工具」。對應 108 課綱「生 J-A2 工具與機具的選用與安全使用」。
  • 安全：剝下來的外皮碎屑要丟到垃圾桶，學生戴護目鏡（線可能彈飛）。
  • 失敗反饋：銅芯有刻痕的線重接電路時容易在彎折處斷裂——讓學生親手體驗一次（剪兩段，一段完整一段刻痕，反覆彎折比較）。
  • 共用工具：建議 2–3 人一組共用一支剝線鉗 + 一組兩鉗組合。檢查鉗口是否有缺口。
  • 進階：有興趣的學生可進一步研究 IPC-A-620 Class 2/3 與 NASA-STD-8739.4 的差異（消費級 vs 太空級工藝要求）。
