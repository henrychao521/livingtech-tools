從模型到實體：3D 列印 / 雷射 / CNC

Onshape 設計好後送到三大數位加工機具的完整工作流。對應書 Ch 7。

① 三大數位加工方式對照

每種方式各有適合的材料、輸出檔案、優缺點。設計初期就要決定要用哪種加工，會影響建模方式。

加工方式 類型 Onshape 輸出 材料 優點 缺點
🖨️ 3D 列印加法STLPLA / PETG / ABS / 樹脂任意形狀（含中空、有機曲面）速度慢（幾小時～整天）、強度有層方向性
🔪 雷射切割減法DXF3mm 木板、壓克力、紙板快、邊緣乾淨、價格便宜只能 2D 切割（厚度固定 = 材料厚度）
⚙️ CNC 雕刻減法STL 或 STEP → CAM 軟體生 G-code木材、壓克力、鋁、銅強度高（單一塊材）、表面細緻需 CAM 軟體、加工前要懂銑床基本、廢料多

② 3D 列印工作流

  1. Onshape doc → 在 Part Studio 標籤右鍵 → 匯出 → 格式選 STL
  2. 勾選「將獨特的零件匯出成個別檔案」（重要！不勾的話拼圖會變成一坨）
  3. 下載 STL（多個零件會包成 zip）
  4. 在切片軟體（Cura / PrusaSlicer / Bambu Studio）開啟 → 排版 → 設定參數
  5. 儲存 G-code → 送到 3D 印表機 → 等待列印 → 取件 → 後處理

💡 詳細的切片參數、故障排除請參考 3D 印表機平台 →。本平台 Onshape 模組與 3D 印表機模組是設計與製造的接力關係。

③ 雷射切割工作流

  1. Onshape doc → 建立 Drawing（工程圖）
  2. 把每個零件投影到圖頁（例：身體 1 張、左右側腳 各 1 張）
  3. 在工程圖標籤右鍵 → 匯出 → 格式選 DXF
  4. 下載 DXF → 在雷射軟體（RDWorks / LightBurn）開啟
  5. 設定速度 + 功率（依材料而定）→ 送雷射機切割

④ CNC 雕刻工作流

  1. Onshape 設計完成 → 匯出 STL（或 STEP，更精確）
  2. 送 CAM 軟體（Roland MDX-40A 的 SRP Player、Fusion 360 CAM、Easel 等）
  3. 選擇加工方式（多數機台有預設範本）
  4. 選擇刀具與材料 → 預覽刀軌
  5. 輸出 G-code → 送 CNC 加工

⚠️ 安全提醒：CNC 加工前必須對銑床、銑刀、材料特性有初步了解。書中強調這是「具備強度但需要安全意識」的加工方式。
