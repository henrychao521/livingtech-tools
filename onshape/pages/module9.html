機電整合應用

把 Onshape 學到的能力與真實機電結合：兩個書中專題 — iPOE A5 四輪自走車改裝、指尖陀螺製作。對應書 Ch 8。

已完成 0 / 2 專題

① 專題一：DIY 自走車改裝（Arduino → iPOE A5 四輪路跑車）

把 Arduino 三輪車改造成四輪驅動。書中明確兩個要解決的問題：

🎯 問題 1：三輪 → 四輪

Arduino 原為三輪車，穩定性差。改造為前後各兩輪的四輪結構。

🎯 問題 2：四輪空轉

四輪若非四輪驅動且結構過剛，遇地形落差時前輪被抬起會空轉。解法：前後輪車體中間加 625ZZ 軸承形成可旋轉機構。

設計流程

  1. 測量：用游標卡尺測 Arduino 電路板大小、孔位（同一個角落或邊作參考避免出錯）
  2. 繪圖：在 Onshape 畫前後車體 + 軸承座 + 結構支撐（脆弱處加肋）
  3. 列印：注意「受力方向」— 3D 列印件最弱在層間黏合。範例書中講鏡架 90° 列印會斷，車體也是同樣道理
  4. 組裝：用螺絲鎖上，含 625ZZ 軸承做旋轉接點

💡 另一種做法：用雷射切割 3mm 板材組裝（書中也有示範，建中周俊丞、賴政嘉同學作品）。

② 專題二：指尖陀螺製作

用 Onshape 設計可旋轉的指尖陀螺，重點：軸承尺寸選定 + 環狀複製排列。

關鍵設計參數

608ZZ 軸承（中央）

外徑 22mm、內徑 8mm、厚度 7mm

三軸夾角

每軸間夾 120°（用尺規作圖法繪製）。書中用 X 軸 ±30° 作輔助線。

外圓直徑

範例用 30mm（軸承外徑 22mm + 兩側 4mm 結構）

中心距

中央軸到外圍軸 25mm（直線長度）

關鍵 Onshape 操作

  1. 畫中央 22mm 圓（軸承位置）
  2. 畫 25mm 輔助直線，末端加上另一個 22mm 圓
  3. 用尺規作圖法（X 軸 ±30°）建立 120° 夾角的三條軸線
  4. 修剪 不需要的線段（直接刪除比剪刀工具有效率）
  5. 環狀複製排列：全選 (Ctrl+A) → 環狀複製 → 預設 3 個（也可改 5 瓣等變化）
  6. Extrude 4mm 厚度（依手感調整）

③ 互動：機電整合判讀

給 4 個設計情境，選正確處理方式。
