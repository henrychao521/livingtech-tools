MODULE 07 ・ 進階專題

動物拼圖設計

用 Onshape 的「圖片置入 + 不規則曲線描繪 + 多角度組合 + DXF 輸出」做出可雷射切割的拼圖。對應書 Ch 6。

① 完整工作流：6 步驟

珩宇老師以三角龍為例的設計流程。每步驟點開卡片標記已學。

② 設計重點對照

📷 圖片置入

「+」(插入新元素) → 匯入 → 選圖檔 → 上傳完成後在草圖中用「插入影像」→ 拖出矩形定位圖片。圖片變成草圖背景參考。

📐 圖片尺寸對齊

用「尺寸」工具設定圖片符合作品大小（範例 120mm）。把動物的腳對齊 Top 平面 — 之後拼圖才會站得起來。

✏️ 不規則曲線描繪

用 Spline（不規則曲線）沿輪廓線描繪。必須回到起始點形成封閉曲線（會出現橘色框框）才能 Extrude。彎折大的地方分段畫再修剪。

🔄 偏移平面（Offset Plane）

畫腳要用：右側平面 → 右鍵 → 偏移平面 → 設定偏移距離（例 15mm）。兩腳分前後 → 建兩個偏移平面（雙箭頭改方向）。

📏 與 Top 平面相切

畫腳的曲線要設定「曲線與 Top 平面相切」 — 確保腳底是平的，動物可以平穩站在桌上。

🔪 輸出 DXF 雷射切割

建立 Drawing → 工程圖 → 各零件分別擺到圖頁上 → 右鍵 → 匯出 → 格式選 DXF → 拿去雷射切割。

③ 雷射切割材料與設定

  • 常用材料：3mm 木板（椴木、合板）、3mm 壓克力、紙板
  • 厚度 = Extrude 深度。範例書中用 3mm，所以拼圖每片厚 3mm。換 5mm 材料時需重新調 Extrude 深度。
  • 切割參數：木材功率 60–80% 速度 10–20 mm/s；壓克力功率 80–100% 速度 5–10 mm/s（依機型調整）
  • 切口寬度（kerf）：雷射光束會吃掉約 0.1–0.3mm。精密配合的卡榫要預留 kerf。
