教學資源

本平台對應 108 課綱、教學排課建議、學習單範本與工具課程銜接。

📋 排課建議

單元 1（4 節課）：認識與安全

  • 第 1 節：模組 1（認識結構） + 模組 2（安全規範）— 必滿分通關
  • 第 2 節：模組 3（操作步驟）+ 課堂演示
  • 第 3 節：模組 4 模擬練習，課末測驗
  • 第 4 節：實體機具操作（先安全的工具）

單元 2（2–3 節課）：應用與創作

  • 模組 5（創作 / 故障排除）
  • 個人或小組創作專題
  • 成果展示與互評

匯出工具

把當前瀏覽器的進度匯出成檔案，方便傳給老師或備份。

📤

匯出個人進度（JSON）

把所有工具的進度合併成一個 JSON 檔。學生用此檔交給老師。

📊

匯出班級表（CSV）

需先在「班級彙整」分頁上傳學生檔案。產生 Excel 可開啟的 CSV 表。

🔄

匯入個人進度

從之前匯出的 JSON 檔還原進度。可用來在不同電腦間同步。

🗑️

清除本機進度

把本機所有工具的進度清空（不可復原）。
