本機學生進度

從這台瀏覽器（學生個人裝置或共用電腦）讀取的當前進度。

教學現場建議流程

  1. 學生在自己裝置上完成學習
  2. 點選工具首頁的「匯出進度」按鈕
  3. 把 JSON 檔交給老師
  4. 老師在「班級彙整」分頁上傳所有學生的檔案

班級進度彙整

上傳多名學生的進度 JSON 檔（從學生「匯出進度」取得），系統會合併成班級總表。

匯出與匯入

把當前瀏覽器的進度匯出成檔案，方便傳給老師或備份。

匯出個人進度（JSON）

把所有工具的進度合併成一個 JSON 檔。學生用此檔交給老師。

匯出班級表（CSV）

需先在「班級彙整」分頁上傳學生檔案。產生 Excel 可開啟的 CSV 表。

匯入個人進度

從之前匯出的 JSON 檔還原進度。可用來在不同電腦間同步。

清除本機進度
